# Writing Coach (가제) — 글 종류별 AI 첨삭 웹앱 설계

날짜: 2026-05-04
작성자: 이천송정초 이선학
대상: 22개정 교육과정 초등 글쓰기 활동 (단원평가·일기·독후감·자율 글쓰기)

---

## 1. 한 줄 정의

학생이 글의 종류(설명문·논설문·뉴스 기사·문학·시 등)를 직접 선택해 글을 쓰면, 그 종류에 맞는 한국 국어과 평가 루브릭으로 **맞춤법·구조·맥락·표현**을 AI가 분석하여 학생이 **스스로 자가 첨삭**할 수 있도록 도와주는 단일 사용자 웹앱. **교사-학생 연결 서버 없음**, 학생이 직접 사용.

---

## 2. 핵심 설계 원칙

| 원칙 | 의미 |
|---|---|
| **학생 1인 자기주도** | 교사 매개·학급 코드·SSO 없음. 학생이 즉시 접속·사용 |
| **로컬 우선 (Local-first)** | 학생 글·첨삭 이력 모두 브라우저(IndexedDB) 저장. 서버 0 |
| **글 종류별 차별 분석** | 시·뉴스기사·논설문이 같은 루브릭일 수 없음. 각각 다른 평가 항목 |
| **격려 우선 톤** | 비판이 아닌 성장 안내. 학생 자존감 보호 |
| **AI는 코치, 작가가 아님** | 글을 대신 써주지 않음. 학생이 쓴 글을 분석만 |

---

## 3. 다루는 글의 종류 (한국 22개정 교육과정 기준)

| # | 글 종류 | 핵심 평가 항목 | 관련 단원 |
|---|---|---|---|
| 1 | **설명하는 글 (설명문)** | 정의·예시·열거·비교·분류 구조, 객관성, 정확한 정보 | 5-1 자신의 경험 살려 글쓰기·6-1 적절한 근거로 주장하는 글쓰기 |
| 2 | **주장하는 글 (논설문)** | 서론(문제 제기)·본론(주장-근거)·결론, 근거의 타당성 | 6-1 (나) 3단원 적절한 근거로 주장하는 글쓰기 |
| 3 | **뉴스 기사** | 표제·부제·전문(리드)·본문, 육하원칙, 객관성, 인용 | 6-1 (나) 1단원 복합양식 매체 자료 만들기 |
| 4 | **이야기·동화 (문학)** | 인물·사건·배경, 발단-전개-위기-절정-결말, 묘사 | 4~6학년 문학 단원 |
| 5 | **시** | 비유(직유·은유)·운율·시어의 함축성·행과 연 구분 | 5~6학년 시 단원 |
| 6 | **일기** | 사건·생각·느낌의 균형, 솔직성, 자기 성찰 | 전 학년 일상 활용 |
| 7 | **독후감** | 책 정보·줄거리·인상·교훈·나의 적용 | 5-1 (가) 1단원 같은 주제의 책을 읽고 생각 나누기 |
| 8 | **편지글** | 받는 사람·인사·내용·맺음·날짜·보내는 사람 (6요소) | 5~6학년 |
| 9 | **광고문** | 표제·본문·CTA, 설득 기법, 타깃 분명 | 6-1 (나) 1단원 |
| 10 | **안내문·기록문** | 일시·장소·내용·주의사항, 명료성 | 자율 활동 |

→ 글 종류 선택 시 해당 단원 성취기준이 자동 표시됨.

## 4. ✅ 반드시 포함할 기능 (Must Have)

### 4.1. 글 종류 선택 + 단원 매핑

- 작성 전 글 종류 1개 선택 (10개 중)
- 선택 즉시 **22개정 관련 단원 + 성취기준 + 평가 루브릭** 표시
- 종류별 작성 가이드 (구조·길이·예시 표시)

### 4.2. 글쓰기 에디터

- 한글 IME 충돌 없는 텍스트 에디터
- **자동 저장** (IndexedDB, 5초마다 또는 입력 멈춤 후)
- **글자 수 + 원고지 칸 수 카운트** (한국 학생 친숙)
- 종류별 권장 길이 표시 (시: 50~200자, 논설문: 400~800자)
- 강제 길이 제한 X (안내만)

### 4.3. AI 4단계 첨삭

종류별 다른 평가 차원이지만, 4영역으로 일관된 결과 제공:

| 영역 | 분석 항목 |
|---|---|
| ① **맞춤법·문장** | 띄어쓰기·맞춤법·문장 부호·문장 호응 |
| ② **구조** | 글 종류에 맞는 구조 부합 (논설문이면 주장-근거 명확성, 시면 행·연 구분) |
| ③ **맥락·논리** | 문단 간 연결, 논리 비약, 일관성, 종결 표현 |
| ④ **표현·어휘** | 종류에 맞는 어휘 선택 (시면 함축적 표현, 설명문이면 객관적 표현) |

### 4.4. 인라인 시각 피드백

- 틀린 부분 **밑줄·하이라이트**
- 클릭 시 **풍선 설명**: 무엇이 틀렸는지 + 어떻게 고치면 좋을지 제안 (단, 자동 수정 X — 학생이 직접 고침)
- 영역별 색상 구분: 빨강(맞춤법)·파랑(구조)·초록(맥락)·노랑(표현)

### 4.5. 종합 코멘트 + 격려 메시지

- 4영역별 짧은 코멘트 (각 2~3줄)
- **항상 잘한 점 먼저, 개선점 나중**
- 마지막 격려 한 줄 ("이 글에서 ○○이 특히 좋았어요. 다음에는 △△을 해보면 어떨까요?")
- 점수는 영역별 4단계 (잘함·괜찮음·노력·다시) — **숫자 점수 X**

### 4.6. 자가 첨삭 워크플로

- AI 피드백 → 학생이 직접 텍스트 수정 → "다시 분석" 클릭
- **수정 이력 보관** (1차·2차·3차 글 + 각 회차의 피드백 비교)
- 회차별 발전을 시각화 ("3차에 맞춤법이 5건 → 1건으로 개선")

### 4.7. 결과 출력 (PDF)

- 한국어 폰트(Pretendard·Noto Sans KR) 정확 렌더링
- A4 1~2페이지 PDF
- 포함 내용: 학생 글 + 4영역 코멘트 + 회차별 비교
- 학생이 부모님·교사에게 보여줄 수 있는 학습 결과물

### 4.8. 로컬 저장 (서버 없음)

- 모든 글·이력은 IndexedDB
- 서버 0, 별도 회원가입·로그인 0
- 글 목록 화면에서 본인의 모든 글 조회·재첨삭 가능

### 4.9. 22개정 교육과정 정합성

- 글 종류 선택 시 관련 단원 표시
- 평가 루브릭이 한국 국어과 성취기준과 부합
- 평가 어휘는 한국 초등 수준에 맞게 (어려운 문법 용어 회피)

## 5. ➕ 추가로 포함하면 좋은 기능 (Nice to Have)

### 5.1. 글쓰기 전 활동 (Pre-writing)

- **설명문**: 주제·하위 항목 마인드맵 작성판
- **논설문**: 주장 1개 + 근거 3개 정리표
- **시**: 비유 떠올리기 ("바람을 ○○에 비유한다면?")
- **이야기**: 인물 카드·사건 흐름 6컷
- 학생이 글쓰기 전에 구조를 미리 짜는 부담 완화

### 5.2. 음성 입력·출력 (TTS/STT)

- 학생이 말로 입력 → 텍스트 변환 (저학년·다문화 학생 친화)
- 자기 글 읽어주기 (TTS) — 객관적 자가 점검 도구

### 5.3. 연령 맞춤 톤

- 학년 선택 (3·4·5·6학년) → AI 첨삭 어휘 조절
- "주술 호응" 대신 "주어와 서술어가 잘 어울리지 않아요" 같은 친숙 표현

### 5.4. 가벼운 게이미피케이션

- 글쓰기 완성 시 자가 첨삭 회차에 따라 배지
- "3번 고쳐서 완성한 끈기 작가" 같은 격려성 배지
- **점수·랭킹·타인 비교 X** — 본인 성장만 시각화

### 5.5. 글 종류별 모범 예시

- 학생이 막막할 때 "예시 보기"
- 자체 큐레이션 또는 22개정 교과서 공개 예시 활용 (저작권 OK 자료만)

### 5.6. 일일 글쓰기 챌린지

- 매일 다른 주제 추천 (저작권 무료 사진 + 짧은 프롬프트)
- 학생 자율 동기 부여
- 강제 X (선택 사항)

### 5.7. 자가 평가 체크리스트

- 학생이 직접 자기 글을 체크하는 종류별 루브릭
- AI 평가와 자가 평가 비교 → 메타인지 향상

### 5.8. 접근성

- 다크/라이트 모드
- 큰 글씨 모드 (시각 보조)
- 키보드 전용 조작
- 색약 친화 색상 (단순 색상 외 패턴 병기)

### 5.9. 출력 다양화

- PDF / 인쇄 / 이미지 캡처 / 텍스트 복사
- **빈 원고지 PDF 출력** (학생이 손으로 옮겨쓰기 학습)

### 5.10. 글쓰기 통계 (개인용, 본인만 보임)

- 본인이 가장 자주 쓰는 글 종류
- 회차별 첨삭 4영역 변화 추이
- 누적 글쓰기 글자 수
- **타인과 비교 X**

### 5.11. 학생 자기 다짐 / 목표

- 글 작성 전 "이번 글에서 신경 쓸 점" 1줄 입력 (예: "주장을 명확하게 쓸 거야")
- 첨삭 후 그 목표 달성 여부 자가 체크

## 6. ❌ 절대 포함하면 안 되는 점 (Must NOT)

### 6.1. 개인정보 수집

- 실명·학교·학년·생년월일 강제 입력 ❌
- 학번·이메일·휴대폰 번호 ❌
- **「개인정보보호법」·「아동·청소년 개인정보 보호 가이드라인」 위반 위험**
- 저장 필요 시 IndexedDB(브라우저 로컬)에만, 서버 전송 0

### 6.2. AI가 글을 대신 써주는 기능

- "주제만 입력하면 AI가 글 자동 작성" ❌
- "이 부분 AI가 자동으로 채워줄게" ❌
- 학습 본질과 정면 충돌. **글은 학생 본인이 쓴다.**
- 단, 글 쓰기 전 가이드·예시 표시는 OK
- 단, 맞춤법·문장 단위 수정 제안은 OK (자동 적용 X, 학생이 손으로 수정)

### 6.3. 타인 비교·순위·점수 경쟁

- 다른 학생과 점수 비교 ❌
- 학급/전국 랭킹 ❌
- "당신은 평균보다 ○○ 점 낮습니다" ❌
- 글쓰기는 **자기 성장의 영역**. 평가가 아닌 성찰의 도구
- 학생 자존감 손상 위험

### 6.4. 부정적·비판적 톤

- "이 글은 잘못 썼다", "엉망이다", "기본도 안 됐다" ❌
- "당신의 글에는 ○○가 없습니다" 같은 부재 강조 표현 ❌
- 항상 **격려 + 구체적 개선점**: "○○이 잘 표현되었어요. △△을 더하면 더 좋아질 거예요"
- AI System Prompt에 톤 가드 명시

### 6.5. 절대화된 점수

- "당신의 글은 75점입니다" ❌
- 100점 만점 점수 ❌
- 영역별 4단계 등급 또는 색상 ✅ (잘함·괜찮음·노력·다시)
- 점수가 절대 평가로 받아들여지지 않게

### 6.6. 외부 서버 저장·공유

- 학생 글이 서버에 저장 ❌
- 클라우드 자동 백업 ❌
- 학생 글이 AI 모델 학습 데이터로 사용 ❌ (Gemini API `noLog` 옵션 또는 OpenAI Platform 데이터 사용 거부 설정)
- 단, 학생이 명시적으로 PDF 출력·저장은 OK (본인 의지)

### 6.7. 학생 글의 외부 공유 버튼

- 트위터·인스타·카카오톡·페이스북 직접 공유 버튼 ❌
- 학생이 의도하지 않은 공개·노출 위험
- PDF 다운로드는 OK (본인이 의식적으로 결정)

### 6.8. 광고·인앱 결제·소셜 로그인

- 학교 환경 부적절
- Google·Naver·카카오 로그인 ❌ (개인정보 연결 위험)
- 학생이 결제 화면에 노출되는 것 자체 차단

### 6.9. 시간 압박·타이머

- "30분 안에 완성하세요" ❌
- 글쓰기는 천천히 깊게. 22개정 「과정 중심 평가」와 부합
- 단, 학생이 직접 타이머 설정하는 것은 OK

### 6.10. 강제 길이 제한

- "최소 500자 이상이어야 분석 가능" ❌
- 시는 50자, 일기는 1000자 가능
- 종류별 적정 길이는 안내만, 강제 X

### 6.11. 부적절 내용

- AI가 욕설·비속어·차별 표현 생성 ❌ (System Prompt에 명시 + 출력 필터링)
- 학생 글에 부적절 단어 감지 시 → 부드러운 안내 ("이 표현은 글에 어울리지 않을 수 있어요")
- 처벌·신고 X

### 6.12. 타인의 글 첨삭

- 친구 글을 가져와 평가받는 기능 ❌
- 본인 글만 첨삭
- 작성 시작 시 "내가 직접 쓴 글입니다" 체크박스로 의도 확인 (선택)

### 6.13. 학년·학교 강제 인증

- 학교 코드·학급 코드 ❌
- 학년만 옵션으로 (선택 입력, 첨삭 톤 조절용)

## 7. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | React 19 + TypeScript + Vite 7 | CineEdu·Survivor Brawl과 동일 — 빠른 MVP |
| 스타일 | Tailwind CSS 4 | 일관성 |
| 에디터 | Tiptap (또는 contenteditable) | 한국어 IME 친화 + 인라인 마킹 가능 |
| 로컬 저장 | IndexedDB (Dexie.js) | 큰 텍스트 + 첨삭 이력 저장 |
| AI | Google Gemini 2.5 Flash | 한국어 자연스러움 + JSON 구조화 출력 + Vercel Functions로 BYOK 가능 |
| PDF 출력 | jsPDF + html2canvas | CineEdu와 동일 (한국어 폰트 검증됨) |
| 폰트 | Pretendard / Noto Sans KR | 한국어 정확 렌더링 |
| 배포 | Vercel | Serverless Functions로 Gemini API 키 보호 |

## 9. 글 종류별 프롬프트 설계 핵심

각 글 종류는 별도 system prompt를 사용하며, 평가 차원이 다름.

### 예: 논설문 평가 프롬프트 (요약)
```
당신은 초등학교 교사입니다. 학생이 쓴 논설문을 다음 4영역으로 평가해주세요.
[학년: {grade}, 작성 의도: "{goal}"]

학생 글:
{text}

평가 항목:
1. 맞춤법·문장: 띄어쓰기, 문장 부호, 주술 호응
2. 구조: 서론(문제 제기) - 본론(주장 + 근거 2개 이상) - 결론 명확성
3. 맥락·논리: 근거의 타당성, 논리 비약 없음, 일관성
4. 표현·어휘: 객관적 어휘, 단정·과장 표현 자제

출력 형식 (JSON):
{
  "praise": "잘한 점 1줄",
  "scores": { "spelling": "잘함|괜찮음|노력|다시", "structure": "...", "context": "...", "expression": "..." },
  "feedback": [
    { "area": "structure", "snippet": "원문에서 발췌한 부분", "comment": "구체적 개선 제안" },
    ...
  ],
  "encouragement": "다음 글쓰기에 도움될 한 줄 격려"
}

규칙:
- 반드시 잘한 점 먼저 언급
- 비판 톤 절대 사용하지 마세요
- 학년 수준에 맞는 어휘 사용
- AI가 직접 글을 고쳐 제시하지 마세요 (학생이 직접 고침)
```

### 예: 시 평가 프롬프트 (다른 차원)
```
[시 평가 - 다른 평가 항목]
1. 맞춤법: 시는 의도된 행 분리·띄어쓰기는 인정 (지시할 때 신중히)
2. 구조: 행과 연 구분, 시상의 흐름
3. 맥락: 시의 주제 일관성, 화자의 감정 표현
4. 표현·어휘: 비유(직유·은유), 운율, 함축적 시어, 감각적 표현
```

→ 종류별 평가 항목이 다르므로, 종류별로 프롬프트를 분리해서 관리.

## 10. 제안서 작성 시 강조할 차별 포인트

| 비교 항목 | 기존 첨삭 도구 (Grammarly·Hanspell·메스봇 등) | Writing Coach (본 작품) |
|---|---|---|
| 글 종류 구분 | 무관 (일반 글) | 10가지 종류별 차별 평가 |
| 평가 기준 | 영문 기반 또는 단순 맞춤법 | 한국 국어과 성취기준 부합 4영역 |
| 자가 첨삭 워크플로 | 자동 수정 위주 | 학생이 직접 고치도록 안내만 |
| 학생 격려 톤 | 기계적 표시 | 잘한 점 우선 + 격려 메시지 |
| 한국 단원 매핑 | 0 | 22개정 + 아이스크림미디어 단원 매핑 |
| 개인정보 보호 | 계정 필요 | 익명 + 로컬 저장 |
| AI가 글 대신 써주기 | 일부 ChatGPT류는 가능 | 절대 X (학습 본질 보호) |
| 점수·랭킹 경쟁 | 일부 (Grammarly Score 등) | 절대 X (자기 성장만) |
| 학생 자존감 | 무관심 | 핵심 가치 |

## 11. 향후 확장 방향 (정식 채택 후)

- 영어 글쓰기 (영어 단원과 매핑)
- 손글씨 사진 업로드 → OCR → 첨삭 (Gemini Vision)
- 학부모 모드 (자녀 글 통계 보기, 단 학생 동의 후)
- 교사 콘솔 (학급 학생 글 모음 관람, 학생 동의 후)
- 글쓰기 도전 시즌제 (월간 주제 + 우수작 익명 전시)

## 12. 핵심 차별화 한 줄 선언

> 「Writing Coach」는 학생이 **글의 종류를 직접 선택해 글을 쓰면**, 한국 국어과 성취기준에 부합하는 4영역(맞춤법·구조·맥락·표현)으로 AI가 분석하여 **학생이 스스로 자가 첨삭하도록 안내**하는 단일 사용자 웹앱입니다. 교사 매개·서버·계정·점수 경쟁 없이, **학생 한 명의 글쓰기 성장 자체**를 최우선 가치로 둡니다.
