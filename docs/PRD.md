# Writing Coach — PRD (Product Requirements Document)

**제품명 (가제)**: Writing Coach
**버전**: 1.0
**작성일**: 2026-05-04
**작성자**: 이천송정초 이선학
**대상**: 22개정 교육과정 초등 글쓰기 활동

---

## 1. 제품 개요

학생이 ① **글감을 찾고**, ② **첫 문장을 시작**한 뒤, ③ **글의 종류**(설명문·논설문·뉴스 기사·문학·시 등)에 맞춰 본문을 작성하면, ④ AI가 한국 국어과 4영역 루브릭으로 **첨삭 피드백**을 제공하고, ⑤ 학생이 **스스로 자가 첨삭**해 글을 다듬는 단일 사용자 웹앱.

**한 줄 가치 제안**: 뤼튼처럼 글의 시작을 도와주되, 본문은 학생이 직접 쓰고, AI는 첨삭 코치 역할만 한다.

## 2. 목표 / 비목표 (Goals / Non-Goals)

### 2.1. 목표 (Goals)

| # | 목표 |
|---|---|
| G1 | 학생이 글감 부족·첫 문장 막막함 때문에 글쓰기를 시작도 못 하는 문제를 해소 |
| G2 | 글의 종류별로 맞춤 첨삭(맞춤법·구조·맥락·표현)을 제공하여 한국 국어과 성취기준 부합 |
| G3 | 학생이 AI 피드백을 보고 **스스로 글을 고쳐가는 자가 첨삭 경험**을 제공 |
| G4 | 별도 회원가입·서버 없이 로컬에서 즉시 사용 가능 |
| G5 | 22개정 교육과정 + 아이스크림미디어 단원과 정합성 보장 |

### 2.2. 비목표 (Non-Goals) — **명시적으로 하지 않음**

| # | 하지 않을 것 | 이유 |
|---|---|---|
| N1 | AI가 글의 본문을 자동 작성 | 학습 본질 위반 |
| N2 | 음성 입력·출력 (TTS/STT) | 복잡도 ↑, MVP 단순성 우선 |
| N3 | 일일 챌린지·주간 추천 주제 | "글쓰기·피드백" 핵심에 집중 |
| N4 | 개인 통계·글쓰기 누적 시각화 | 단순성 우선 |
| N5 | 학생 자기 다짐 입력·게이미피케이션 배지 | 단순성 우선 |
| N6 | 교사·학부모 콘솔, 학급 코드, SSO | 학생 1인 자기주도 |

| N8 | 점수 경쟁·랭킹·타인 비교 | 학생 자존감 보호 |

## 3. 사용자·시나리오

### 3.1. 페르소나

**P1. 글감이 떠오르지 않는 학생** (초 4~6학년)
- 교실에서 글쓰기 시간이 주어졌지만 무엇을 쓸지 막막
- 일기·독후감 주제 정하기 어려움
- 시는 어떻게 시작해야 할지 모름

**P2. 글은 쓰지만 첨삭 없이 그대로 제출하는 학생**
- 자기 글이 잘 썼는지 모름
- 누군가 봐주길 원하지만 매번 부탁할 수 없음
- 부모님·교사도 30명 학급에서 일일이 봐주기 어려움

### 3.2. 핵심 시나리오

**S1. 시작이 막막한 학생**
1. 학생이 "독후감을 써야 하는데 뭘 쓸지 모름"
2. 글 종류 = 독후감 선택 → 키워드 입력 ("나무위에서 꿈을 꾸는 아이")
3. **글감 찾기** → AI가 8개 후보 제시 ("주인공의 꿈에서 배운 점", "나의 비슷한 경험" 등)
4. 학생이 1개 선택 → **첫마디 뽑기** → 첫 문장 후보 3개 → 학생이 영감만 받고 자기 문장 작성
5. 본문 작성 → 첨삭 받음 → 자가 수정

**S2. 글은 다 썼는데 봐달라**
1. 학생이 자기 글을 가지고 있음 (또는 직접 입력)
2. 글 종류 = 논설문 선택
3. 글감·첫마디 단계 건너뛰고 바로 에디터로
4. 글 붙여넣기/입력 → "분석하기"
5. AI 첨삭 → 인라인 피드백 → 자가 수정 → 재분석

## 4. 핵심 기능 (Must Have, P0)

### F1. 글 종류 선택 + 단원 매핑

**요구사항**
- 10종 중 1개 선택 (설명문·논설문·뉴스 기사·이야기·시·일기·독후감·편지글·광고문·안내문)
- 선택 즉시 22개정 관련 단원 + 성취기준 + 권장 길이 표시
- 종류별 작성 가이드 (구조·예시) 펼치기 가능

**완료 기준 (Acceptance Criteria)**
- 10종 모두 선택 가능
- 단원 매핑 정확 (5학년/6학년 국어 단원 + 자율 활동)
- 선택 변경 시 가이드도 변경

---

### F2. 글감 찾기 (Topic Finder) ★ 신규

**요구사항**
- 학생 입력: 글 종류 + 키워드/관심사/책 제목 (자유 텍스트, 1~2줄)
- 학생 학년 (선택 옵션)
- AI 출력: **글감 6~8개**, 각각:
  - 글감 제목 (1줄)
  - 글감 짧은 설명 (1~2줄, "이 글감으로는 이런 내용을 쓸 수 있어요")
- 학생이 1개 선택 → 다음 단계로 (첫마디 또는 바로 작성)
- "마음에 드는 게 없어요" → 다른 8개 다시 받기

**Acceptance Criteria**
- 학년·글 종류·키워드에 부합하는 글감 제시
- 부적절 주제(폭력·차별·성적 내용) 자동 필터링
- 학생이 글감 없이도 진행 가능 (선택 사항)

**제약**
- AI는 글감 **제목과 짧은 설명만** 제공. **본문 미리보기·예시 글 X**

---

### F3. 첫마디 뽑기 (Opening Sentence Helper) ★ 신규

**요구사항**
- 학생 입력: 글 종류 + (선택한 글감 또는 자유 입력 주제)
- AI 출력: **첫 문장 후보 3개**, 각각 다른 접근법
  - 후보 1: 정공법 (주제 직접 제시)
  - 후보 2: 질문·궁금증으로 시작
  - 후보 3: 장면·묘사로 시작 (시·이야기에 적합)
- 각 후보 옆에 "이런 느낌이에요: ○○" 짧은 설명
- **명시적 안내문**: "이 문장을 그대로 옮기지 마세요. 비슷한 느낌으로 자신의 문장을 만들어 보세요."
- 학생이 후보를 클릭해도 **자동 입력 X**. 직접 보고 자기 문장으로 변형해서 입력

**Acceptance Criteria**
- 3개 후보가 서로 다른 접근법
- 글 종류에 적합한 어조·문체 (시면 함축적, 뉴스기사면 객관적)
- "다른 후보 보기" 가능
- 학생이 첫마디 단계 건너뛰기 가능

**제약**
- AI는 **첫 문장 1개씩만** 제공. 첫 단락·본문·결론 미리 작성 X
- 학생 글 작성란에 자동 삽입 안 됨 (학생이 직접 타이핑해야 함)

---

### F4. 글쓰기 에디터

**요구사항**
- 한글 IME 충돌 없는 텍스트 에디터 (Tiptap 또는 contenteditable)
- **자동 저장**: 입력 멈춤 후 3초 또는 5초마다 IndexedDB에 저장
- **글자 수 + 원고지 칸 수 카운트** (실시간)
- 종류별 권장 길이 표시 (시: 50~200자 / 논설문: 400~800자 / 뉴스: 200~500자)
- 권장 길이 미달·초과 안내만 (강제 X)
- 단축키: Ctrl+Z 실행 취소, Ctrl+S 즉시 저장 (기본 동작)

**Acceptance Criteria**
- 한글 입력 시 IME 깨짐 없음
- 새로고침해도 글 유지
- 글자 수 카운트가 한글·영문 모두 정확

---

### F5. AI 4영역 첨삭

**요구사항**
- "분석하기" 버튼 클릭 → AI 호출 (Gemini 2.5 Flash)
- **4영역 평가**, 글 종류별 다른 루브릭 적용:

| 영역 | 모든 종류 공통 분석 |
|---|---|
| ① 맞춤법·문장 | 띄어쓰기·맞춤법·문장 부호·주술 호응 |
| ② 구조 | 글 종류에 맞는 구조 (논설문: 주장-근거 / 시: 행과 연 / 뉴스: 표제·전문·본문) |
| ③ 맥락·논리 | 문단 간 연결, 논리 비약, 주제 일관성 |
| ④ 표현·어휘 | 종류에 맞는 어휘 (시: 함축적 / 설명문: 객관적) |

- **4단계 등급** (잘함·괜찮음·노력·다시) — **숫자 점수 X**
- 각 영역마다 짧은 코멘트 + 인라인 마킹할 부분 1~5개 지정
- 분석 시간 5~15초 안에 완료, 진행 표시

**Acceptance Criteria**
- 부정적·비판적 톤 절대 사용 안 함 (system prompt로 강제)
- 잘한 점 먼저 언급 → 개선점 나중
- 학년 수준에 맞는 어휘 (어려운 문법 용어 회피)

---

### F6. 인라인 시각 피드백

**요구사항**
- 4영역별 색상 마킹:
  - 🔴 빨강: 맞춤법·문장
  - 🔵 파랑: 구조
  - 🟢 초록: 맥락·논리
  - 🟡 노랑: 표현·어휘
- 마킹 부분 클릭 시 풍선 설명: "이 부분은 ○○때문에 이렇게 고치면 더 좋을 수 있어요"
- **수정 제안만 제공, 자동 수정 적용 X** (학생이 직접 타이핑해서 수정)

**Acceptance Criteria**
- 같은 위치에 여러 영역 마킹 시 색상 누적 표시 가능
- 풍선이 화면 가장자리 안에 보이도록
- 모바일에서도 탭으로 풍선 표시

---

### F7. 종합 코멘트 + 격려 메시지

**요구사항**
- 4영역 등급 한눈에 보이는 결과 패널
- **잘한 점** 카드 (가장 강조, 상단)
- **개선점** 카드 (4영역별 1줄 코멘트)
- **격려 한 줄** (마지막)
- 예시:
  > "이 글에서 주장이 분명하게 드러난 점이 좋았어요. 다음에는 근거에 구체적인 예를 한 가지 더 들어보면 더 설득력 있는 글이 될 거예요. 잘하고 있어요!"

**Acceptance Criteria**
- "당신의 글은 ○○점입니다" 같은 절대 점수 표시 절대 금지
- 항상 격려 한 줄로 마무리
- 영역별 등급은 색상 + 단어로 표시 (텍스트만 보는 학생도 이해)

---

### F8. 자가 첨삭 워크플로

**요구사항**
- 학생이 피드백 보고 글 직접 수정
- "다시 분석하기" 클릭 → 새 첨삭
- **회차별 이력 보관** (최대 5회까지)
- 회차 비교 화면: 1차 ↔ 2차 ↔ 3차 글 + 각 회차의 4영역 등급 변화
- 발전이 있으면 시각적 강조 ("맞춤법: 노력 → 잘함으로 발전!")

**Acceptance Criteria**
- 회차 간 글이 동일하면 새 회차 안 만듦 (변경된 경우에만)
- 학생이 이전 회차로 되돌리기 가능
- 회차별 글 + 첨삭 이력 IndexedDB에 보관

---

### F9. 결과 출력 (PDF)

**요구사항**
- 한국어 폰트(Pretendard·Noto Sans KR) 정확 렌더링
- A4 1~2페이지 PDF 자동 생성
- 포함 내용:
  - 학생 글 (최종본)
  - 글 종류 + 관련 단원
  - 4영역 등급 + 코멘트
  - 회차 발전 요약 (선택)
- "PDF로 저장" 버튼 1회 클릭으로 다운로드

**Acceptance Criteria**
- 한글 깨짐 없음
- 모바일에서도 다운로드 작동
- 파일명: `글쓰기_{글종류}_{날짜}.pdf`

---

### F10. 로컬 저장 (서버 0)

**요구사항**
- 모든 학생 글·첨삭 이력은 IndexedDB (Dexie.js)
- 서버 전송 0 (단, AI API 호출 시 글 본문은 Gemini API에 일시 전송 — `noLog` 옵션으로 학습 데이터 사용 거부)
- "내 글 목록" 화면에서 본인 글 조회·재첨삭 가능
- "글 삭제" 버튼 (브라우저 storage에서 영구 삭제)

**Acceptance Criteria**
- 새로고침·브라우저 종료 후에도 글 유지
- 다른 브라우저·기기에서는 다른 데이터 (의도된 동작)
- 동일 브라우저의 시크릿 모드에서는 별도 (의도된 동작)

---

### F11. 22개정 교육과정 정합성

**요구사항**
- 글 종류 10개 각각에 대응하는 단원 매핑 데이터 (TS 정적 모듈)
- 학년·교과(국어 가/나)·단원·성취기준·핵심 개념
- 평가 어휘를 초등 학년 수준에 맞춤 ("주술 호응" → "주어와 서술어가 잘 어울려요")

**Acceptance Criteria**
- 5~6학년 국어 단원 우선 매핑 (1차 출시)
- 추후 3~4학년 + 중학교 확장 가능 구조

## 5. 부가 기능 (Should Have, P1)

### F12. 글 종류별 모범 예시

- 막막한 학생을 위해 종류별 1~2개 예시 글 제공 (자체 큐레이션 또는 저작권 OK 자료)
- "예시 보기" 버튼 → 모달로 표시
- "예시는 참고만 하고 자기만의 글을 쓰세요" 안내

### F13. 자가 평가 체크리스트

- 글 작성 후 "분석하기" 전에 학생이 자기 글을 직접 체크하는 5~7개 항목
- 종류별 다른 체크리스트 (예: 논설문 → "주장이 분명한가? / 근거가 2개 이상인가? / 결론이 있는가?")
- AI 첨삭 결과와 자가 평가 비교 → 메타인지 학습

### F14. 접근성

- 다크/라이트 모드 토글
- 큰 글씨 모드 (시각 보조)
- 키보드 전용 조작 (Tab·Enter·Esc)
- 색약 모드 — 4영역 색상에 패턴 병기 (점선·실선·이중선·점)

| 영역 | 요건 |
|---|---|

## 9. 데이터 모델 (IndexedDB)

```ts
// IndexedDB Schema (Dexie.js)

interface Writing {
  id: string;                    // UUID
  type: WritingType;              // '설명문' | '논설문' | '뉴스기사' | '이야기' | '시' | '일기' | '독후감' | '편지글' | '광고문' | '안내문'
  grade?: 3 | 4 | 5 | 6;          // 선택 (첨삭 톤 조절용)
  topic?: string;                 // 글감 (선택)
  title?: string;                 // 글 제목 (선택)
  createdAt: number;
  updatedAt: number;
  revisions: Revision[];          // 회차별 글 + 첨삭 (최대 5)
}

interface Revision {
  index: number;                  // 1, 2, 3, ..., 5
  text: string;                   // 학생 글 본문
  feedback: Feedback | null;      // null이면 아직 분석 안 함
  selfCheckResults?: boolean[];   // 자가 평가 체크리스트 결과 (선택)
  timestamp: number;
}

interface Feedback {
  praise: string;                 // 잘한 점 1~2문장
  scores: {
    spelling: Grade;              // '잘함' | '괜찮음' | '노력' | '다시'
    structure: Grade;
    context: Grade;
    expression: Grade;
  };
  inlineMarks: InlineMark[];      // 인라인 마킹 데이터
  encouragement: string;          // 격려 한 줄
  generatedAt: number;
}

interface InlineMark {
  area: 'spelling' | 'structure' | 'context' | 'expression';
  startOffset: number;            // 글 본문 내 위치
  endOffset: number;
  comment: string;                // 풍선 설명
}

type Grade = '잘함' | '괜찮음' | '노력' | '다시';
```

## 11. AI 프롬프트 설계 (요약)

### 11.1. 글감 찾기 프롬프트

```
역할: 한국 초등 글쓰기 코치
입력:
- 글 종류: {writingType}
- 학년: {grade}
- 학생이 입력한 키워드/관심사: {keywords}

출력 (JSON):
{
  "topics": [
    { "title": "글감 제목", "description": "이 글감으로 쓸 수 있는 내용 1~2줄" },
    ...8개...
  ]
}

규칙:
- 학년 수준에 맞는 글감
- 본문이나 예시 글 절대 제공 X (제목 + 짧은 설명만)
- 부적절 주제(폭력·차별·성적) 자동 제외
- 글 종류에 적합한 글감 (시면 감성적 / 논설문이면 논쟁적 / 뉴스이면 사실적)
```

### 11.2. 첫마디 뽑기 프롬프트

```
역할: 한국 초등 글쓰기 코치
입력:
- 글 종류: {writingType}
- 글감/주제: {topic}
- 학년: {grade}

출력 (JSON):
{
  "openings": [
    { "approach": "정공법", "sentence": "첫 문장 후보 1", "tone": "느낌 설명 1줄" },
    { "approach": "질문형", "sentence": "...", "tone": "..." },
    { "approach": "장면 묘사", "sentence": "...", "tone": "..." }
  ]
}

규칙:
- 첫 문장 1개씩만 (단락·본문 작성 X)
- 학년·종류에 맞는 어휘
- 학생이 그대로 베끼지 않도록, 짧고 영감 위주
- 시는 함축적, 뉴스는 객관적, 이야기는 묘사 중심
```

### 11.3. 4영역 첨삭 프롬프트 (논설문 예시)

```
역할: 한국 초등학교 국어 교사
입력:
- 학년: {grade}
- 글 종류: 논설문
- 학생 글: {text}

출력 (JSON):
{
  "praise": "잘한 점 1~2문장 (글에서 발견한 구체적 강점)",
  "scores": {
    "spelling": "잘함|괜찮음|노력|다시",
    "structure": "...",
    "context": "...",
    "expression": "..."
  },
  "inlineMarks": [
    {
      "area": "spelling|structure|context|expression",
      "snippet": "원문에서 발췌한 부분 (정확히 일치)",
      "comment": "어떻게 고치면 좋을지 제안 (자동 수정 X)"
    }
  ],
  "encouragement": "다음 글쓰기에 도움 될 격려 한 줄"
}

평가 항목 (논설문):
1. 맞춤법·문장: 띄어쓰기, 맞춤법, 주술 호응, 문장 부호
2. 구조: 서론(문제 제기) - 본론(주장 + 근거 2개 이상) - 결론
3. 맥락·논리: 근거의 타당성, 논리 비약, 주제 일관성
4. 표현·어휘: 객관적 어휘, 단정·과장 자제

규칙 (절대):
- "잘못 썼다", "엉망이다", "기본도 안 됐다" 같은 표현 절대 금지
- 항상 잘한 점 먼저 언급
- 학년 수준 어휘 (어려운 문법 용어 회피)
- 100점 만점 점수 출력 X
- AI가 직접 글을 고쳐 제시하지 X (학생이 직접 고침)
- 4영역 외 평가 추가 X
```

각 글 종류(시·뉴스·이야기·일기 등)마다 별도 프롬프트 모듈로 관리.

## 15. 핵심 차별화 한 줄 선언

> 「Writing Coach」는 ① 글감 찾기·첫마디 뽑기로 학생의 **글쓰기 시작 부담**을 해소하되, ② 본문은 **반드시 학생이 직접 작성**하도록 설계하고, ③ 한국 국어과 4영역(맞춤법·구조·맥락·표현)으로 **글 종류별 차별 첨삭**을 제공하여 학생이 **스스로 자가 첨삭하는 글쓰기 학습 경험**을 만드는 단일 사용자 웹앱입니다. 교사 매개·서버·계정·점수 경쟁 없이, 학생 한 명의 글쓰기 성장 자체가 핵심 가치입니다.
